# Roadmap

This is the current roadmap for the public 0.99.1 source export. Historical release notes may describe earlier plans; those statements are not the current roadmap.

## 0.99.1 — Lean Execution Kernel

Implementation is complete. The current phase is product workload stabilization and evidence collection.

The milestone covers correctness, recovery, writer ownership, rollback, review evidence, truthful runtime capability reporting, typed autonomous capability admission, and timing derived from durable evidence.

## 1.0 — Bounded Parallel Execution

Planned scope:

- Stage Ticket
- frozen candidate
- asynchronous Worker and Reviewer execution
- candidate isolation
- Review Package
- candidate-bound Review Receipt
- WIP limits and backpressure
- integration revalidation
- a single canonical publication path

These capabilities are not implemented in 0.99.1.

## 1.1+ — Evidence-driven optimization

Planned scope:

- Evidence Retrieval
- optional Knowledge/RAG/Librarian capabilities
- richer evaluation
- context compression
- evidence-driven optimization and benchmark work

These capabilities are not implemented in 0.99.1.
